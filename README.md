# Cognifyz Data Analysis Internship

A comprehensive data analysis project completed as part of the Cognifyz Technologies Data Analysis Internship.

## Overview

This project analyzes a restaurant dataset to identify patterns and insights related to cuisines, cities, pricing, ratings, online delivery, restaurant chains, votes, and service availability.

The analysis was performed using Python and Jupyter Notebook with libraries including Pandas, NumPy, Matplotlib, Plotly, and NLTK.

## Objectives

- Perform exploratory data analysis on restaurant data.
- Identify trends and patterns across different restaurant attributes.
- Analyze restaurant ratings, votes, pricing, and services.
- Create meaningful visualizations.
- Derive data-driven observations from the analysis.

## Tasks Completed

### Level 1 — Basic Analysis

#### Task 1 — Top Cuisines
- Identified the three most common cuisines.
- Calculated the percentage of restaurants serving each cuisine.
- Visualized cuisine distribution.

#### Task 2 — City Analysis
- Identified the city with the highest number of restaurants.
- Calculated average restaurant ratings by city.
- Identified the city with the highest average rating.

#### Task 3 — Price Range Distribution
- Analyzed restaurant distribution across price ranges.
- Calculated the percentage of restaurants in each price category.
- Created visualizations of the price distribution.

#### Task 4 — Online Delivery
- Calculated the percentage of restaurants offering online delivery.
- Compared average ratings between restaurants with and without online delivery.

### Level 2 — Intermediate Analysis

#### Task 1 — Restaurant Ratings
- Analyzed aggregate rating distribution.
- Identified the most common rating range.
- Calculated average restaurant votes.

#### Task 2 — Cuisine Combination
- Identified common cuisine combinations.
- Compared ratings across cuisine combinations.
- Analyzed the relationship between popularity and average rating.

#### Task 3 — Geographic Analysis
- Plotted restaurant locations using latitude and longitude.
- Analyzed geographic distribution and restaurant concentration.
- Created an interactive restaurant location map.

#### Task 4 — Restaurant Chains
- Identified restaurant chains based on repeated restaurant names.
- Analyzed restaurant chain ratings and popularity.
- Compared chains based on number of outlets and customer engagement.

### Level 3 — Advanced Analysis

#### Task 1 — Restaurant Reviews
- Examined the dataset for customer review text.
- Documented the limitation that the provided dataset does not contain free-form customer review text.
- Performed supplementary analysis of the available rating categories.

#### Task 2 — Votes Analysis
- Identified restaurants with the highest and lowest numbers of votes.
- Calculated the correlation between votes and aggregate ratings.
- Visualized the relationship between votes and ratings.

#### Task 3 — Price Range vs Online Delivery and Table Booking
- Analyzed online delivery availability across price ranges.
- Analyzed table booking availability across price ranges.
- Compared service availability between different price categories.
